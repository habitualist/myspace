# FC Bridals & More

**Affordable Luxury for All Occasions**

FC Bridals & More is a fashion design house specializing in female wardrobe styling for all occasions, ranging from casuals and corporate wear to owanbe styles and bridal styling. We offer a perfect blend of affordability, elegance, and simplicity.

## Features

-   **Comprehensive Services**: Showcasing Custom Outfits, Ready-to-Wear, Bridal Styling, and more.
-   **Responsive Design**: Optimized for various devices to provide a seamless browsing experience.
-   **Smooth Navigation**: Easy access to different sections like Home, Services, Gallery, and Contact.
-   **Interactive Elements**: Smooth scrolling, mobile menu toggle, and scroll animations.

## Technologies Used

-   **HTML5**: Semantic markup for structure.
-   **CSS3**: Styling, responsive design, and animations.
-   **JavaScript**: Interactivity, mobile menu, and scroll effects.

## Project Structure

-   `index.html`: The main landing page containing all sections (Hero, Services, About, Gallery, Contact).
-   `style.css`: Contains all the styles and responsive rules for the website.
-   `script.js`: Handles the mobile menu, smooth scrolling, and scroll-triggered animations.
-   `asset/`: Directory containing project images.

## Setup & Usage

To view this project locally:

1.  Clone or download this repository.
2.  Open the project folder.
3.  Double-click `index.html` to open it in your web browser.
